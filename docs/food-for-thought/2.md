How to Run & Develop
Start the Stack: Run docker-compose up -d. This gives you empty Neo4j and Redis instances.

Seed the Graph: Run the Cypher script in the Neo4j browser (localhost:7474). This creates your "Python 101" curriculum.

Run the Agent: Start the FastAPI server wrapping tutor_engine.py.

Debug with Langfuse: As you chat, look at the Langfuse dashboard. You will see the Reasoning Chains.

Input: "Is a while loop like an if statement?"

Reasoning Log: strategy: analogy, misconception: confused iteration with selection.

Output: "Think of an 'if' statement like a door you walk through once. A 'while' loop is like a revolving door you stay in until a condition is met."

This architecture ensures that the AI cannot just halluncinate an answer. It is constrained by the Neo4j graph (it can only teach what exists in the graph) and the Pydantic schema (it must diagnose before it speaks).
